## ?? Overview

MovieMemory is a multimedia platform developed with **Flutter** and **Firebase** that allows users to discover, organize, manage, and explore movies and TV series through a modern and intuitive interface.

Originally conceived as a personal media library, the project evolved into a complete multimedia ecosystem featuring personalized lists, public collections, content discovery tools, multilingual support, and integrated streaming capabilities.

## ?? Installation

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- Firebase Project
- TMDB API Key

### Clone Repository

```bash
git clone https://github.com/yourusername/moviememory.git

cd moviememory
```

### Install Dependencies

```bash
flutter pub get
```

### Run Application

```bash
flutter run
```
